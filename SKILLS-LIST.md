# 26 Claude Skills for SEO and AI SEO

SEO is two jobs now. Ranking on Google, and getting quoted by AI.

This folder has 26 skills. Each one is a small instruction file that teaches Claude how to do one SEO job properly, the same way every time. You do not write prompts any more. You say what you want, and Claude picks up the right skill.

---

## What is inside

**AI search and citations (8)**

| Skill | What it does |
|---|---|
| `aiseo-share-of-voice` | One heatmap across ChatGPT, Perplexity, Gemini, AI Overviews and AI Mode |
| `aiseo-prompt-map` | Turns a keyword list into the prompts buyers actually type into AI |
| `aiseo-citation-gap` | Shows the prompts where competitors get cited and you get nothing |
| `aiseo-answer-block` | Rewrites a page so a model can lift one clean quotable passage |
| `aiseo-entity` | Checks whether the models know who you are, not just what you publish |
| `aiseo-source-outreach` | Finds the third-party pages AI keeps citing and drafts the pitch |
| `aiseo-llms-txt` | Generates llms.txt and checks what the AI crawlers can actually read |
| `aiseo-drift` | Compares this month's AI answers to last month and names what changed |

**Content and on-page SEO (6)**

| Skill | What it does |
|---|---|
| `seo-content-brief` | Builds the brief from the live SERP, not from the topic |
| `seo-content-audit` | E-E-A-T and citability checks, with a publish verdict |
| `seo-page` | Keep, refresh, consolidate or kill, per URL |
| `seo-schema` | Detect, validate and generate JSON-LD |
| `seo-sxo` | Scores the page on search experience, from four visitor types |
| `seo-images` | Alt text, WebP, srcset and layout shift |

**Competitor and gap analysis (4)**

| Skill | What it does |
|---|---|
| `seo-competitor-gap-analysis` | Keywords and topics they cover and you do not |
| `seo-competitor-pages` | Takes apart the specific pages beating yours |
| `seo-backlink-gap` | Domains linking to them but not to you |
| `seo-backlinks-profile` | Your own link quality, authority spread and toxic flags |

**Technical SEO (4)**

| Skill | What it does |
|---|---|
| `seo-technical-audit` | Crawlability, indexing, speed, security and mobile in one pass |
| `seo-sitemap` | Sitemap against the latest crawl and against what is indexed |
| `seo-hreflang` | Language codes, return tags and international targeting |
| `seo-firecrawl` | Raw HTML and JSON-LD a standard fetch cannot reach |

**Keywords, local and reporting (4)**

| Skill | What it does |
|---|---|
| `seo-keyword-cluster` | Groups a messy export into pillar and spoke clusters |
| `seo-local` | GBP, NAP consistency and map pack readiness |
| `seo-google` | Reads Search Console and highlights quick wins |
| `seo-plan` | Chains the audits into one phased 90 day plan |

## How to install

See `START-HERE.md` in this folder. It takes about two minutes.

## A good starting order

1. `seo-technical-audit` — fix what is broken first
2. `seo-google` — find the wins already sitting in Search Console
3. `aiseo-prompt-map` then `aiseo-share-of-voice` — get your AI baseline
4. `aiseo-citation-gap` and `seo-competitor-gap-analysis` — find the openings
5. `seo-plan` — turn all of it into 90 days of work
